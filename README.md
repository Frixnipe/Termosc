# Termosc - A real-time oscilloscope in the Windows Terminal

This is just a super simple oscilloscope I wrote in a few days. It runs in the Windows Terminal, visualizing any and every audio playing on your computer in real time. 
*insert video of Termosc working here*
### Why? 
Because I felt like it. I wanted to make a simple oscilloscope. In fact, the actual idea came from [this Reddit post](https://www.reddit.com/r/unixporn/comments/1sd4p36/oc_terminal_oscilloscope_art/) showcasing a terminal oscilloscope for Linux.
### Features
Termosc features a built-in config menu to customize its color, speed and style. Pressing any button on the oscilloscope view opens it. There isn't a lot of options yet, but there are more to come!
### Updates
I still want to add a bunch of features to this; the current version is basically just a prototype. But I'm planning on adding more styling and stuff because why not!
### Download
You can download this from **Winget** (`winget install Termosc`) of from the [Releases page](https://github.com/Frixnipe/Termosc/releases).
